Instant alerts for priority Gmail senders.

A private webhook relay connecting Google Cloud Pub/Sub push notifications directly to Telegram. Zero inbox polling. Runs on Vercel Serverless.

Event Flow
01 Gmail Event → Inbound mail triggers Google Cloud Pub/Sub push notification
02 JWT Verification → Vercel webhook verifies Google OIDC cryptographic signature
03 Metadata Only → Reads sender header & subject via least-privilege Gmail API
04 Telegram Alert → Matches watchlist & delivers instant notification with direct link
Gateway Endpoints
Endpoint Consumer Authentication
/api/gmail-webhook Google Cloud Pub/Sub Google OIDC Bearer Token
/api/telegram-webhook Telegram Bot API Secret Token + Owner ID Check
/api/cron/daily Vercel Cron Bearer CRON_SECRET
/api/oauth/start Initial Setup (Admin) Setup Password + Signed State
Telegram Bot Commands
/add <email>
Watch exact address (e.g. boss@corp.com)
/add <@domain>
Watch entire domain (e.g. @bank.com)
/remove <item>
Remove address or domain from watchlist
/list
List all monitored rules and current status
/check <email>
Test if an address matches active watchlist rules
/pause & /resume
Toggle alert notifications on or off
/status
View watch expiration & last event latency
Security & Architecture Specs
Gmail Scope
gmail.metadata (headers only; body and attachments are inaccessible)
Token Storage
AES-256-GCM encrypted at rest in Upstash Redis
Access Control
Commands strictly restricted to Telegram Owner ID
Idempotency
Redis SET NX deduplication (7-day TTL) prevents duplicate alerts
Watch Renewal
Automated daily cron renewal prevents 7-day watch expiration
